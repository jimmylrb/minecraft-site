🌱 新手入门

刚接触《我的世界》？别慌，跟着这份指南一步步来。

1️⃣ 选择游戏版本

Java 版（Java Edition）

  • 💻 电脑版，最经典，Mod 最丰富
  • 🧩 支持几乎所有 Mod 和光影
  • 🌐 可进各种第三方服务器
  • 购买：minecraft.net 官方

基岩版（Bedrock Edition）

  • 📱 手机 / 平板 / 主机版
  • 🎮 跨平台联机更方便
  • 🧩 Mod 支持有限（有市场）
  • 购买：应用商店 / 主机商店
💡 建议：电脑玩家首选 Java 版（Mod 和服务器生态最好）；手机/平板玩家玩基岩版。如果你不确定，先下个免费试玩版体验一下！

2️⃣ 安装游戏

1

购买正版

在 minecraft.net 或商店购买，支持开发者。

2

安装启动器

官方启动器会自动下载游戏文件。

3

选择版本

想玩 Mod 选 Forge/Fabric 版本。

4

开始游戏

单人世界 or 多人服务器，出发！

3️⃣ 生存第一天（必看）

🌳

白天：砍树！

按住鼠标左键砍树，收集原木 → 合成工作台 → 合成木镐。木头是一切的基础。

🪨

挖石头

用木镐挖石头，合成石镐、石斧、石剑。做出熔炉（烧制用）和火把。

🐑

收集食物

杀动物（牛、羊、猪）或采小麦。饿着肚子会扣血，一定要备好食物。

🌙

天黑前建庇护所

挖个山洞或用方块搭个小屋，关门点上火把。夜晚有僵尸、骷髅和苦力怕！

💎

第二天：挖矿

向下挖矿（注意岩浆！），先找铁，再做钻石镐挖黑曜石，准备去下界。

❓ 常见问题（FAQ）

游戏卡顿/帧数低怎么办？

调低渲染距离、关掉粒子效果，更新显卡驱动；电脑配置低可以装 OptiFine（优化 Mod）。

怎么和朋友联机？

局域网：同一个 WiFi 直接多人游戏即可。异地：使用服务器（见"服务器"页）或第三方联机工具。

找不到钻石怎么办？

钻石生成在 Y=16 以下，最集中的层数是 Y=11 左右。用鱼骨挖矿法（主道+分支）效率最高。

苦力怕怎么对付？

看到它后退保持距离，用剑或弓远程击杀；也可以让它靠近后打断它的"膨胀"再打。

怎么防止家被炸/被偷？

服务器里用锁箱插件；单人玩做好备份；家里别放贵重物品，重要东西随身带。
